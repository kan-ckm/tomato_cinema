# web

Frontend của hệ thống **Tomato Cinema**, xây dựng với **Next.js 16**.

## Chức năng

- Giao diện người dùng cho nền tảng đặt vé xem phim
- Tích hợp với gateway-service qua REST API
- Hỗ trợ Telegram OAuth đăng nhập

## Tech Stack

- **Next.js 16** — React framework
- **React 19**
- **TypeScript**
- **`@repo/ui`** — Shared UI components

## Cài đặt

```bash
pnpm install
```

## Chạy

```bash
# Development
pnpm dev
# Truy cập: http://localhost:3500

# Build production
pnpm build
pnpm start
```
