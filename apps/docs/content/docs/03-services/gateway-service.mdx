---

`gateway-service` là điểm đón nhận request duy nhất từ bên ngoài hệ thống.

## Vai trò chính

- **Reverse Proxy & Routing**: Chuyển tiếp request đến service tương ứng.
- **Authentication Guard**: Kiểm tra tính hợp lệ của Access Token trước khi vào mạng nội bộ.
- **Rate Limiting**: Giới hạn số lượng request trên mỗi IP / User để phòng chống DDOS.
- **CORS & Security Headers**: Cấu hình chuẩn Helmet, CSP, CORS cho toàn bộ API.

## Cấu trúc Endpoint

- `/api/v1/auth/*` -> `auth-service`
- `/api/v1/users/*` -> `user-service`
- `/api/v1/media/*` -> `media-service`
- `/api/v1/bot/*` -> `bot-service`
