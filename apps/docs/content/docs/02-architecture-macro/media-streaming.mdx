## Đặc tả kỹ thuật

- **Chuẩn nén:** H.264 (AVC) / H.265 (HEVC) + AAC Audio.
- **Giao thức phân phối:** Apple HLS (`.m3u8` playlist và các segments `.ts`/`.m4s`).
- **Tối ưu hình ảnh Poster:** Tự động nén WebP/AVIF đa kích thước (thumbnail, banner, mobile).
